## [EN] e_LootSearch

A highly configurable DayZ mod that allows players to search static objects (like fridges, lockers, and garbage bins) for loot.

### Features
**Interactive Searching:** Players can search static environment props using their hands or specific tools.
**Custom Loot Tables:** Define exactly what items can be found in each type of object, including min/max amounts and drop weights.
**Visual Config Generator:** Includes an offline HTML tool (`ConfigGenerator.html`) that parses your server's `types.xml` for auto-complete.

### Configuration
The mod configuration is located at `$profile:e_Mods/e_LootSearch.json`. Use `ConfigGenerator.html` to easily edit it. Refer to `SERVER_PROPS_GUIDE.md` for valid targets.
